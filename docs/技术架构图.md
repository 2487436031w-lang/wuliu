# 智慧路灯 — 技术架构图

> 依据当前仓库：端侧 BearPi、云端 Spring Boot、Web「灯廊」、PostgreSQL、EMQX。  
> 契约真源：`smart-street-light-master/API文档.md`。

## 1. 总体技术架构

```mermaid
flowchart TB
  subgraph user["使用层"]
    Browser["浏览器 · 灯廊 Vue3"]
  end

  subgraph app["应用层 :8080 / :5173"]
    Vue["web/ · Vite 开发服 5173"]
    Boot["smart-street-light-master · Spring Boot 8080"]
  end

  subgraph bus["消息与实时"]
    EMQX["EMQX Broker · MQTT 1883"]
    WS["STOMP WebSocket · /ws"]
  end

  subgraph data["数据层"]
    PG["PostgreSQL + pgvector"]
  end

  subgraph edge["设备层"]
    Pi["BearPi-HM Nano"]
    Lux["光照传感器"]
    Lamp["LED 路灯"]
  end

  Browser --> Vue
  Vue -->|"HTTP JSON · Header token"| Boot
  Boot --> WS
  WS --> Browser
  Boot --> PG
  Boot <--> EMQX
  Pi --> Lux
  Pi --> Lamp
  Pi <-->|"Topic smart-light/{deviceSn}/…"| EMQX
```

## 2. 分层说明

| 层 | 技术 | 仓库位置 | 职责 |
|----|------|----------|------|
| 表现 | Vue 3、Vue Router、Pinia、Vite | `web/` | 登录、总览、设备、光照、告警、阈值、日志；默认可 Mock |
| 应用 | Spring Boot 3、JWT、MyBatis-Plus | `smart-street-light-master/` | REST、阈值判定、心跳扫描、MQTT 下发、WS 推送 |
| 消息 | MQTT（EMQX）、STOMP/WebSocket | 实验室 Docker / 后端配置 | 灯↔云上报与指令；云→浏览器实时刷新 |
| 数据 | PostgreSQL、pgvector | `sql/schema.sql` | 用户、设备、光照、控制日志、阈值、告警、知识块 |
| 设备 | BearPi + 传感器 + LED | `firmware/`（源码多在板端本机） | 采光、心跳、执行开关、状态回传 |

## 4. 后端内部（经典三层）

```mermaid
flowchart TB
  C["Controller 门口"] --> S["Service 规则"]
  S --> M["Mapper / SQL"]
  MQTT["MqttConfig 订阅/下发"] --> S
  T["HeartbeatCheckTask 每30秒"] --> S
  S --> WS["SimpMessagingTemplate 推 /topic"]
  M --> DB[(PostgreSQL)]
```

确定层在 Service：光照比阈值 → `AUTO_ON` / `AUTO_OFF`；心跳超时 → `OFFLINE` + 告警。网页与板子都不自己算规则。
