# 跨部门协作区（Collab）

> **用途：** 前端 / 后端 / 端侧 / 产品 / 答辩材料之间传「需求、决策、接口意图、联调信息」。  
> **原则：** 聊天不算数；写进本目录（或 `docs/contracts/`）才算对齐。  
> **维护：** 谁发起谁写；对方回复可直接改同文件或开 `收件箱/` 新条。

## 怎么用

| 你要… | 放哪里 |
|--------|--------|
| 问对方要不要做某功能 | `收件箱/` 用模板新建一条 |
| 告诉对方「我们决定了什么」 | `决策/` |
| 主动提供给某部门的说明 | `发件箱/` |
| 改字段 / 加接口 | 同时改 `docs/contracts/` + `changelog.md`，并在收件箱知会 |

状态词：`待回复` → `已确认` → `已落地` / `搁置`

## 目录

| 路径 | 说明 |
|------|------|
| [决策/](决策/) | 产品与接口边界决策（注册、分期接口等） |
| [发件箱/](发件箱/) | 我们主动提供给其他部门的信息包 |
| [收件箱/](收件箱/) | 向其他部门提的需求 / 对方回传 |
| [模板-变更请求.md](模板-变更请求.md) | 复制后填进收件箱 |
