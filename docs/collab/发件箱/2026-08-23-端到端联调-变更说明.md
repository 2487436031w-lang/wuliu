## 一、配置方式

### 1. 云端（PC）

仓库：https://github.com/xikunn/wuliu

```powershell
git clone https://github.com/xikunn/wuliu.git
cd wuliu

# 1) 启动 PostgreSQL + EMQX + 后端
cd smart-street-light-master
powershell -ExecutionPolicy Bypass -File scripts\run-local.ps1

# 2) 手机热点场景：允许 EMQX 1883 入站（管理员 PowerShell，一次即可）
powershell -ExecutionPolicy Bypass -File scripts\allow-mqtt-hotspot.ps1

# 3) 前端 HTTP 模式
cd ..\web
copy .env.example .env.local
npm install
npm run dev
```

| 项 | 值 |
|----|-----|
| Web | http://localhost:5173 |
| 后端 API | http://localhost:8080（Vite 代理，勿填 `VITE_API_BASE`） |
| 登录 | `admin` / `admin123` |
| EMQX | `localhost:1883`，控制台 http://localhost:18083 |
| PostgreSQL | `localhost:5433` |
| 真机设备 | 仅 `SN-RM-001`（人民路001号路灯） |

### 2. 板端（BearPi + E53_SC1）

```powershell
cd wuliu
powershell -ExecutionPolicy Bypass -File firmware\scripts\setup-hardware-e2e.ps1 `
  -WifiSsid "实验室2.4G_WiFi" `
  -WifiPsk "班群告知的密码" `
  -DeviceSn "SN-RM-001" `
  -BrokerIp "PC的WLAN_IP"
```

- `BrokerIp`：板子能 ping 到的 PC IP（手机热点时多为 `172.20.10.x` 网段的 PC 地址）
- 生成 `firmware/streetlight/streetlight_config.h`（已 gitignore，勿提交含密码的文件）
- 同步到 `D:\ohos\bearpi-hm_nano` 并启用 `E_streetlight_mqtt` sample

```bash
# WSL 编译
bash /mnt/d/ohos/tools/compile-c3.sh

# 烧录（先关串口监视器）
powershell -ExecutionPolicy Bypass -File D:\ohos\tools\flash-c3.ps1 -Port COM3 -StopMonitor
```

### 3. 开关灯阈值

Web → **阈值**（`/threshold`），或总览/光照页点击横幅进入。

| 字段 | 含义 | 默认 |
|------|------|------|
| 开灯阈值 | 光照 **低于** 此值且灯为关 → `AUTO_ON` | 30 lux |
| 关灯阈值 | 光照 **高于** 此值且灯为开 → `AUTO_OFF` | 80 lux |
| 心跳超时 | 超时未上报则离线告警 | 180s |

室内验证自动开灯：可把开灯阈值调到 **200** 左右，或完全盖住 BH1750。

## 二、使用方法（验收路径）

1. **后端 LIVE**：`run-local.ps1` 后 `curl` 登录返回 `code=200`
2. **前端 LIVE**：侧栏显示 `HTTP 后端 · LIVE`（WebSocket 连通）
3. **板上电**：串口 115200 出现 `MQTT connected` + 约 **1 秒** 一次 `published light`
4. **总览**：实时光照数字随板子变化
5. **设备页**：对 `SN-RM-001` 开灯/关灯，板子 GPIO_7 响应
6. **遮光**：lux 低于开灯阈值 → 自动开灯（后端下发 `AUTO_ON`）
7. **告警**：设备离线等告警在告警页点 **处理** → 状态变「已处理」

无板调试 MQTT：

```powershell
cd smart-street-light-master
powershell -ExecutionPolicy Bypass -File scripts\mqtt-simulate.ps1 -DeviceSn SN-RM-001 -Intensity 25
```

## 三、本次改动摘要

### 固件 `firmware/streetlight/`

- 合并 C3 传感器 + D5 MQTT，topic 对齐 `smart-light/{deviceSn}/…`
- **修复主循环卡死**：MQTT socket 非阻塞 + 短 `MQTTYield`，避免无下行时不再上报光照
- 上报周期约 **1 秒**；BH1750 连续测量模式
- 命令在主线程序列处理，避免 MQTT 回调里直接控 GPIO
- 脚本：`setup-hardware-e2e.ps1`、`configure-streetlight.ps1`、`register-streetlight-build.ps1`

### 后端 `smart-street-light-master/`

- 测试数据仅保留 `SN-RM-001`；设备列表按 id 排序
- MQTT 下发日志改为 INFO；`allow-mqtt-hotspot.ps1` 防火墙规则
- `mqtt-simulate.ps1` 修正 JSON 引号问题

### 前端 `web/`

- HTTP 模式：Vite 代理 REST + `/ws`；清除 mock token
- API 字段归一化（`normalize.ts`）；雪花 ID 告警用 **string**，修复「处理」无反应
- 实时光照轮询 3s；设备/告警/总览 WS 驱动刷新
- **阈值页**对所有登录用户开放；总览与光照页展示当前阈值
- 登录页后端连通性提示；空 HTTP 响应不再 `json()` 崩溃

### 仓库卫生

- `.gitignore` 忽略 `.cursor/skills/` 等本地 IDE 文件（从版本库移除已跟踪的 skills）
- `streetlight_config.h` 本地生成，不提交
