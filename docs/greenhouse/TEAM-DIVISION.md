| 表面 | Responsible | Accountable | Consulted |
|------|-------------|-------------|-----------|
| **棚体布局 / 坐标真源** | 产品+联调 | 组长 | 后端、前端、硬件 |

| MQTT 契约 `smart-greenhouse/` | 后端 | 组长 | 硬件、前端 |
| HTTP `/greenhouse/**` | 后端 | 组长 | 前端 |
| 光场/重庆日型仿真 | 后端 | 组长 | 前端（展示） |
| 场务总览 / 冠层页 | 前端 | 组长 | 后端 |
| Docker PG+EMQX / 迁移脚本 | 联调 | 组长 | 后端 |
| 真机适配器 | 硬件 | 组长 | 后端 |

**原则：** 一事一主责；改 Topic/字段必须先改 `docs/greenhouse/contracts/*` 再改代码。
