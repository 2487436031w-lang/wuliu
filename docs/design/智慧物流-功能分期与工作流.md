# 智慧物流 — 功能分期与项目工作流

## 功能分期

### MVP（可评分的物联网闭环）

- 车辆/设备管理，货物—车辆绑定  
- GPS 或同构模拟定位上报（MQTT）  
- 货主：实时位置、轨迹、ETA  
- 三类告警可演示：偏航、异常停留、开箱（杜邦按键）  
- 调度指令下发 → 蜂鸣/LED + ack  
- 司机状态：装货 / 在途 / 送达；告警日志  
- 调度端：1 真机 + N 模拟车分布  
- AI：可暂缓，或不阻塞主演示  

**演示一句话：** 绑定 → 上报 → 看轨迹 → 告警 → 下发响板 → 送达  

### 进阶（AI 进入主链）

- 告警自动研判（结构化结论 + 证据，写进告警详情）  
- 调度副驾：采纳建议 → 人确认 → 原 MQTT 下发  
- 运单智能速览（货主页）  
- 对话入口复用同一工具（事实问答 + 薄 RAG）  
- 定位双模切换稳定、指令审计（judgment → command）  

**演示一句话：** 告警弹出带解释 → 一键采纳调度 → 板子执行  

### 最终（完整交付 + 答辩加分）

- 老师 11 条用户故事全覆盖、五角色可切换  
- 认知层齐全：研判 + 副驾 + 叙事 + 对话（知识/事实分流）  
- 多信号复合研判（如偏航+开箱）、研判可进告警日志筛选  
- 室外真 GPS 补录 + 室内 sim 答辩方案  
- 文档：需求/接口/演示脚本/答辩提纲齐全  

**不做：** 无确认自动下发、用 LLM 替代阈值、纯百科闲聊当核心

## 项目工作流

```
选题对齐老师清单
    ↓
概念设计（基础版冻结）+ AI 深化专项
    ↓
正式需求（验收标准）+ MQTT/API 草案
    ↓
W1 端云连通：上报、绑定、轨迹、地图
    ↓
W2 规则告警 + 指令 ack + 司机状态
    ↓
W3 AI 认知层（先模板研判，再接模型）
    ↓
联调演示脚本 → 室外补录 → 答辩材料
```

| 阶段 | 产出 | 负责人侧重（示意） |
|------|------|--------------------|
| 需求冻结 | PRD、MoSCoW | 全员对齐 |
| 端侧 | GPS/sim、开箱、蜂鸣 ack | 嵌入式 |
| 云侧 | 接入、规则、运单、指令 | 后端 |
| 前端 | 五角色、地图、告警/调度页 | 前端 |
| 智能 | 研判/副驾/叙事/对话 | 后端+前端 |
| 收尾 | 演示路径、答辩、风险说明 | 全员 |

**原则：** 先通确定层（无 AI 也能走完老师双流程），再挂认知层；AI 可降级，主链不可断。
